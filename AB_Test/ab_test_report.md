# 광고 A/B 테스트 분석 보고서

## 1. 분석 목적과 가설

본 분석의 목적은 광고 그룹(`ad`)과 공익광고 그룹(`psa`)의 사용자 전환율이 다른지 확인하는 것이다. 그룹의 의미는 `psa`가 공익광고 대조군이라는 데이터 정의를 전제로 한다.

전환율 = 전환한 사용자 수 ÷ 전체 사용자 수

- 귀무가설 H₀: 두 그룹의 모집단 전환율은 같다.
- 대립가설 H₁: 두 그룹의 모집단 전환율은 다르다.
- 유의수준: 0.05
- 검정 방향: 양측검정

광고가 전환율을 높이는 경우와 낮추는 경우를 모두 고려했다. 결과 확인 이후 정리한 분석이므로 사전 등록된 실험 계획으로 간주하지 않는다.

## 2. 데이터 점검

분석에는 `marketing_AB.csv`를 사용했다. 사용자 한 명을 하나의 분석 단위로 삼았다.

| 점검 항목 | 결과 |
|---|---|
| 전체 행 수 | 588,101행 |
| 컬럼 수 | 7개 |
| 결측치 | 없음 |
| 중복 사용자 ID | 없음 |
| 동일 사용자의 여러 그룹 등장 | 없음 |
| 처치 라벨 | ad, psa |
| 전환 여부 | True/False |
| 제거한 행 | 0행 |

사용자 ID 중복이 없어 한 사용자가 여러 번 집계되는 문제는 발견되지 않았다. 분석에서는 전환 여부를 계산용 0과 1로 변환했으며, 모든 행을 유지했다.

CSV의 저장 인덱스인 `Unnamed: 0`은 완전 중복 비교에서만 제외했다. 원본 데이터를 삭제하지 않았다.

처리 기록: 기본 점검에서 분석을 막는 문제가 발견되지 않아 588,101행을 모두 유지했다.

다만 배정 라벨과 실제 광고 노출을 독립적으로 대조할 정보가 없으므로, 이러한 점검만으로 실제 노출까지 정확했다고 판단할 수는 없다.

## 3. 배정 비율과 SRM 평가의 한계

### 3.1 관측 배정 비율

| 그룹 | 사용자 수 | 관측 비율 |
|---|---:|---:|
| 광고 그룹(ad) | 564,577명 | 약 96% |
| 공익광고 그룹(psa) | 23,524명 | 약 4% |

두 그룹의 크기는 크게 다르지만, 불균형 자체만으로 배정 오류라고 판단할 수는 없다.

### 3.2 SRM을 평가하지 못한 이유

SRM은 실제 그룹 크기를 **사전에 계획한 배정 비율에 따른 기대 인원**과 비교한다.

이 데이터에서는 계획 배정 비율을 확인하지 못했다. 따라서 기대 인원을 정할 수 없어 SRM을 평가하지 않았다.

관측 비율이 약 96:4라는 이유로 계획 비율을 96:4로 설정하지 않았다. 그렇게 하면 관측값으로 비교 기준까지 정하게 되어 배정 이상을 점검하는 의미가 사라진다.

SRM 상태는 ‘평가 불가’이며, 통과 또는 실패가 아니다.

### 3.3 보조 점검의 방법과 역할

계획 배정 비율이 없어 SRM을 평가할 수 없으므로, 이와 별개로 사용자 중복과 노출 패턴을 점검했다. 아래 점검은 SRM의 대체 검정이나 무작위 배정의 합격 판정이 아니다.

| 점검 항목 | 방법 | 해석 범위 |
|---|---|---|
| 사용자 중복 | `user id`의 중복 및 동일 사용자의 여러 처치 라벨 등장 확인 | 사용자 중복 집계와 그룹 간 중복 확인 |
| 주요 노출 요일·시간대 | 그룹 내 비율 비교, 카이제곱 독립성 검정, Bonferroni 보정, Cramér’s V | 노출 패턴 차이와 연관성 크기 확인 |
| 총 광고 노출량 | 평균·표준편차·중앙값·분위수와 상자그림·누적분포 비교 | 사용자별 노출량 분포의 탐색적 비교 |

사용자 ID 중복과 여러 그룹에 등장한 사용자는 발견되지 않았다. 중복이나 라벨 충돌이 발견되는 경우에는 임의로 삭제하지 않고 분석을 중단하여 원인과 처리 기준을 확인하도록 했다. 중복이 없다는 사실만으로 사용자 간 독립성이 입증되는 것은 아니다.

### 3.4 요일·시간대 검정의 기준

`most ads day`와 `most ads hour` 각각에 대해 그룹과 범주의 교차표를 만들고 카이제곱 독립성 검정을 수행한다. 귀무가설은 그룹에 따라 해당 범주의 분포가 다르지 않다는 것이다.

두 검정을 함께 수행하므로 각 p값에 2를 곱하고 최댓값을 1로 제한하는 Bonferroni 보정을 적용한다. 보정 p값을 유의수준 0.05와 비교한다. 모든 기대 빈도가 5 이상인지 확인하고, 이 기준을 충족하지 않으면 근사 p값의 해석을 보류한다.

큰 표본에서는 작은 분포 차이도 통계적으로 유의할 수 있어 Cramér’s V를 함께 확인한다. 보정 p값이 0.05 이상이어도 두 분포가 동일하다고 결론 내리지 않는다. 구체적인 보정 p값과 기대 빈도 조건 충족 여부는 노트북의 점검 결과표에서 확인한다.

### 3.5 보조 점검의 한계

요일·시간대·총 노출량은 실험 중 노출 기록에서 만들어진 처치 후 변수일 수 있다. 따라서 이 비교를 실험 전 공변량 균형 검증으로 표현하지 않는다. 분포 차이가 있어도 배정 오류로 단정할 수 없으며, 분포가 비슷해도 무작위 배정이 입증되지 않는다.

노출 관련 변수를 기준으로 사용자를 제외하거나 전환율을 보정하지 않는다. 특히 처치 후 변수로 조건을 제한하거나 보정하면 편향이 생길 수 있다.

**SRM은 계속 평가 불가로 남는다.** 전환율 결과는 사용자 간 독립성 등 통계적 전제를 가정한 탐색적 비교이며, 인과 효과로 해석하려면 무작위 배정 방식과 배정·노출 로그, 수집 및 측정 과정을 추가로 확인해야 한다. 이 보고서는 전환 결과 확인 후 정리한 분석으로, 사전 등록된 분석 계획이 아니다.

## 4. 노출 패턴과 그래프 해석

이 절은 노트북에서 작성한 그래프의 해석을 정리한다. 그래프 이미지 자체는 이 파일에 포함하지 않았다.

### 4.1 요일별 막대그래프

요일별 그래프는 각 그룹에서 **해당 요일이 주요 광고 노출 요일인 사용자의 비율**을 보여준다. 해당 요일에 발생한 광고 노출 건수의 비율은 아니다.

두 그룹의 크기가 다르므로 인원수가 아닌 그룹 내 비율로 비교했다.

| 주요 노출 요일 | ad | psa |
|---|---:|---:|
| 목요일 | 14.01% | 16.60% |
| 토요일 | 13.96% | 12.15% |
| 일요일 | 14.58% | 13.00% |

공익광고 그룹은 목요일 비중이 더 높고, 광고 그룹은 주말 비중이 더 높았다.

요일과 그룹의 연관성을 나타내는 **Cramér’s V는 약 0.020**이었다. 분포 차이는 존재하지만 전체적인 연관성의 크기는 작게 나타났다.

이 차이가 배정 오류, 광고 운영 방식, 사용자 행동 중 무엇에서 비롯됐는지는 현재 데이터만으로 구분할 수 없다.

### 4.2 시간대별 선그래프

시간대별 그래프는 해당 시간이 주요 광고 노출 시간인 사용자의 비율을 보여준다. 동일 사용자의 하루 행동을 추적하는 그래프는 아니다.

두 그룹 모두 오전부터 비중이 증가해 정오 전후에 높아지는 패턴을 보였다. 13시가 주요 노출 시간인 사용자 비율은 광고 그룹 약 8.06%, 공익광고 그룹 약 9.22%였다.

그룹과 시간대의 Cramér’s V는 약 0.018이었다. 전체적인 연관성은 작지만, 시간대별 사용자 비중이 완전히 같지는 않았다.

### 4.3 총 광고 노출량 상자그림

상자그림은 사용자별 총 노출량의 중앙값과 가운데 50% 범위를 비교한다.

| 항목 | ad | psa |
|---|---:|---:|
| 평균 | 24.82회 | 24.76회 |
| 중앙값 | 13회 | 12회 |
| 25번째 백분위수 | 4회 | 4회 |
| 75번째 백분위수 | 27회 | 26회 |
| 90번째 백분위수 | 56회 | 59회 |
| 99번째 백분위수 | 201회 | 206회 |
| 최댓값 | 2,065회 | 907회 |

두 그룹의 평균과 가운데 분포는 유사했다. 평균이 중앙값보다 상당히 높아 일부 사용자의 많은 노출량이 평균을 끌어올리는 오른쪽 꼬리 분포임을 알 수 있다.

상자그림에서는 극단값의 점 표시만 생략했다. 해당 데이터를 삭제한 것은 아니다. 수염 끝은 반드시 전체 최솟값·최댓값을 뜻하지 않는다.

광고 그룹의 최댓값이 더 크다는 사실만으로 그룹 전체의 노출량이 더 많다고 판단해서는 안 된다. 그룹 크기 차이도 극단값 관측에 영향을 줄 수 있다.

### 4.4 총 광고 노출량 누적분포

누적분포는 특정 노출량 이하인 사용자가 각 그룹에서 몇 %인지 보여준다.

같은 노출량에서 선이 더 높다면 그 값 이하인 사용자가 더 많다는 뜻이다. 두 선이 교차하면 구간별 관계가 달라 한 그룹이 일관되게 더 많이 노출됐다고 요약하기 어렵다.

큰 값까지 표시하기 위해 가로축에는 로그 계열 눈금을 사용했다. 따라서 그래프에서 같은 가로 간격이 같은 노출 횟수 차이를 의미하지 않는다.

### 4.5 분포 점검의 해석 범위

요일·시간대·노출량은 실험 중 노출 기록으로 만들어진 처치 후 변수일 수 있다. 따라서 분포가 다르다는 이유로 배정 오류라고 판단하거나, 비슷하다는 이유로 무작위 배정이 정상이라고 판단하지 않는다.

Cramér’s V는 분포의 연관성을 나타내는 보조 효과 크기이다. 광고의 전환 효과를 나타내는 지표로 사용하지 않는다.

## 5. 전환율 검정 선택 근거

전환 여부는 이진 변수이며, 서로 다른 사용자로 구성된 두 그룹의 전환 비율을 비교하므로 **두 비율 z검정**을 사용했다.

각 그룹의 전환·미전환 수가 충분해 정규근사를 적용했다. 그룹 크기가 다르더라도 검정할 수 있으며, 크기를 맞추기 위해 광고 그룹을 임의로 줄이지 않았다.

- 검정에는 귀무가설 아래 **합동 표준오차**를 사용했다.
- 전환율 차이의 신뢰구간에는 **비합동 표준오차**를 사용했다.

이 분석은 사용자 간 독립성 등 통계적 전제를 가정한다. 표본 수 차이에 따른 불확실성은 반영하지만, 배정 편향이나 수집 오류를 보정하지는 않는다.

## 6. 검정 결과와 효과 크기

### 6.1 그룹별 전환율

| 항목 | ad | psa |
|---|---:|---:|
| 사용자 수 | 564,577명 | 23,524명 |
| 전환 사용자 수 | 14,423명 | 420명 |
| 전환율 | 2.555% | 1.785% |

### 6.2 점추정·신뢰구간·효과 크기

| 지표 | 결과 |
|---|---:|
| 절대 전환율 차이(ad − psa) | +0.769%p |
| 차이의 95% 신뢰구간 | +0.595%p ~ +0.943%p |
| 상대 비율(ad / psa) | 1.431배 |
| 상대 변화율 | +43.09% |
| z통계량 | 7.370 |
| 양측 p값 | 약 1.71 × 10⁻¹³ |

광고 그룹의 관측 전환율은 공익광고 그룹보다 **0.769%p 높았으며, 약 1.431배**였다.

유의수준 0.05에서 귀무가설을 기각했다. 사용자 간 독립성 등 통계적 전제가 성립한다면 두 그룹의 전환율이 다르다는 증거가 있다.

상대 변화율인 “43.09% 높다”만 제시하지 않고 절대 차이인 “0.769%p 높다”를 함께 보고했다. 비율 자료에서는 절대 차이 자체가 점추정이면서 효과 크기이다.

다만 이 결과는 관측된 그룹 간 차이이다. 무작위 배정과 수집 과정을 확인하지 못했으므로 “광고가 전환율을 0.769%p 높였다”는 인과적 결론으로 단정하지 않는다.

## 7. 비용을 고려한 경제성 시나리오

### 7.1 예시 가정

실제 비용 자료가 없어 다음 값을 예시로 사용했다.

| 항목 | 가정 |
|---|---:|
| 도입 대상 사용자 | 100,000명 |
| 추가 전환 1건의 기여이익 | 20,000원 |
| psa 대비 사용자당 추가 비용 | 100원 |
| 고정 도입 비용 | 1,000,000원 |

총 추가 비용은 11,000,000원이다. 전환당 가치는 매출이 아니라 변동비를 차감한 기여이익으로 해석한다. 비교 대상이 psa이므로 비용도 psa 대비 추가 비용이어야 한다.

### 7.2 손익분기 기준

손익분기 전환율 차이 = 총 추가 비용 ÷ (대상 사용자 수 × 전환당 기여이익)

위 가정에서는 손익분기 차이가 **0.55%p**이다. 대상 10만 명에서 추가 전환 550건을 확보해야 비용을 회수한다.

| 항목 | 계산 결과 |
|---|---:|
| 관측 차이를 적용한 추가 전환 수 | 약 769건 |
| 관측 차이를 적용한 순이익 | 약 438만 원 |
| 차이의 신뢰구간 하한 적용 순이익 | 약 90만 원 |
| 차이의 신뢰구간 상한 적용 순이익 | 약 787만 원 |

차이의 신뢰구간 하한도 예시 손익분기 기준을 넘으므로, 가정하에서는 경제적으로 유망한 시나리오다.

그러나 이는 관측 차이를 실제 인과 효과로 사용할 수 있고, 도입 대상에서도 같은 효과가 유지되며, 비용과 전환당 기여이익 가정이 적절하다는 조건을 전제로 한다.

따라서 위 계산을 실제 수익 예측으로 확정하지 않는다. 제시된 범위는 전환율 차이의 불확실성만 반영하며, 미래 이익의 예측구간은 아니다.

## 8. 의사결정

선택: 데이터 추가 수집

관측 전환율 차이는 통계적으로 뚜렷하고, 예시 비용 가정에서도 경제적 가능성이 있다. 그러나 실험 설계와 배정 과정이 확인되지 않아 현재 결과만으로 출시를 확정하지 않는다.

우선 확보할 정보는 다음과 같다.

1. 실험 당시 계획한 배정 비율과 배정 방식
2. 사용자별 배정 로그와 실제 노출 로그
3. 로그 누락 및 분석 대상 포함·제외 기준
4. 그룹별 전환 관찰 기간과 측정 기준
5. 실제 추가 비용과 전환당 기여이익

여기서 추가 수집은 단순히 사용자 수를 늘리는 것을 뜻하지 않는다. **현재 부족한 설계·운영 정보를 먼저 확보하는 것이 핵심**이다.

기존 기록을 확보할 수 없다면 배정 비율, 관찰 기간, 주요 지표와 분석 기준을 사전에 명시한 새로운 실험을 고려한다.

## 9. 한계와 결론의 적용 범위

- SRM 평가 불가: 계획 배정 비율을 확인하지 못했다. 사용자 중복 및 노출 패턴 점검으로 이를 대체하지 않았다.
- 인과 해석 제한: 무작위 배정 과정과 사용자 간 독립성이 확인되지 않았다.
- 처치 후 변수: 노출 관련 변수의 분포가 비슷해도 배정의 적절성이 입증되지 않는다.
- 신뢰구간의 범위: 표본 오차를 표현하며 선택 편향과 수집 오류는 반영하지 않는다.
- 비용 가정: 경제성 계산에는 실제 확인된 비용 대신 예시 값을 사용했다.
- 일반화 제한: 다른 기간이나 대상에서도 같은 차이가 유지되는지는 알 수 없다.
- 탐색적 분석: 결과를 확인한 뒤 정리한 분석을 사전 계획된 확증적 분석으로 표현하지 않는다.

이 데이터에서는 광고 그룹의 전환율이 공익광고 그룹보다 높게 관측됐다. 다만 출시 판단을 위해서는 효과의 통계적 유의성뿐 아니라 배정 과정의 타당성과 실제 경제성을 추가로 확인해야 한다.

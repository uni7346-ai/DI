MCAR : 완전히 무작위, 결측이 어떤 다른 컬럼과도 상관없음, 제거 평균/중앙값 대체 모두 비교적 안전
MAR : 다른 관측된 컬럼이 원인, 결측 비율이 특정 그룹에서 다름, 그룹별 대체 같은 채널연령의 평균 등
MNAR: 결측 값 자체가 원인, 다른 컬럼으로 설명 안되는 쏠림, 단순 대체는 위험, 결측 자체를 '이런 상태였다'는 신호로 보존하거나 별도 모델 

dropna() : 결측행/ 열을 제거

그룹별 transform("median") : 같은 그룹 내 통계량으로 채움
ffill() / bfill() 앞/뒤 값으로 채움
결측 플래그 : 결측이 있었다는 사실을 별도 컬럼에 보존




axis=0 : 위아래(행 방향)로 쌓기
axis=1 : 좌우(열 방향)로 붙이기
ignore_index=True : 합친 뒤 인덱스를 0부터 다시매킴
keys=[...] : 어느 조각에서 왔는지 라벨달기
inner : 교집합(양쪽 모두에 있는 키만)
left : 왼쪽기준(왼쪽은 전부  + 오른쪽은 맞는 것만)
right : 오른쪽기준(오른쪽 전부 + 왼쪽은 맞는 것만)
outer : 합집합(어느 한쪽에라도 있으면 전부)
키중복 : df["key"].duplicated().sum()  행 폭증
짝 안맞는 키 : ~left["key"].isin(right["key"]) 조용한 결측
병합 검증 옵션 : merge(..., validated="m:1") 관계 가정 위반 시 에러로 알려줌
출처 표시 : merge(..., indicator=True) 어느 쪽에서 왔는지 _merge 열로 확인
한 열, 한 함수 : df.groupby("region")["amount"].mean() 지역별 평균 금액
여러 함수 : df.groupby("region")["amount"].agg(["mean", "sum", "count"]) 지역별 평균 합 건수
여러 열 이름 지정 : agg(매출=("amount", "sum", "count")) 보기 좋은 이름의 요약표
여러 기준 : df.groupby(["region", "membership"]) 지역 x 등급 교차 그룹
